书写规范（点开看：支持哪些写法、哪些目前做不到）

选好输入文件后，这里会用你表里真实的教师ID、班级ID举例。

写法一：指定某位老师教某个班的某个学科

  • T30教C05英语 —— 教师ID + 教 + 班级ID + 学科
  • 用等号写效果一样：T30=C05英语
  • 也可以写教师姓名 + 班级名称：张老师教高二(1)班英语
  • 每行一条；行首编号写不写都行（1.T30教C05英语 一样能识别）
  • ⚠️ ID 照抄「教师」「班级」表里的写法：表里是 T30 就写 T30， 不要自己补成 T030（补零的写法也能认，但以表里为准最稳）

写法二：其它要求用「结构化写法」（推荐）

⚠️ 直接写中文句子（如「张老师周二没空」「T48不想周五上课」） 不会生效 —— 引擎只认「教师指定」和下面这种 JSON 两种写法。 不方便手写 JSON 时，用下面「不会写？用 AI 帮你转」那段：软件会生成一份 已脱敏的提示词，复制给任意 AI，把返回的 JSON 粘回来即可。

下面这种 JSON 可以直接整段粘进上面的输入框（连开头结尾的 ```json / ``` 一起粘），能精确表达 5 类要求： 老师某天或某节没空、老师不想某天上连堂、某班某天或某节不排课（该格排自习）、 老师最多带几个班。

```json
{
  "version": 1,
  "constraints": [
    {"type": "teacher_unavailable",   "teacher": "T30", "days": [2]},
    {"type": "teacher_no_double_day", "teacher": "T30", "days": [2]},
    {"type": "class_unavailable",     "class": "C01", "day": 5, "periods": [7, 8]},
    {"type": "teacher_max_classes",   "teacher": "T30", "max": 2}
  ]
}
```
  • days 用 1~5 表示周一到周五；periods 省略＝全天， 节次 1~8（上午 1~5、下午 6~8）
  • 不想手写 JSON？用下面「不会写？用 AI 帮你转」——它会生成一段 已脱敏（姓名自动换成编号）的提示词，复制给任意 AI 即可
  • 写错的那条会被单独跳过并说明原因，不影响其它条目

✘ 目前做不到（写了会提示"这条没生效"，不会排进课表）：

  • 「某老师教的班里必须包含某个班」—— 如：教师T30所教的班级里必须有一个是C05
  • 「两位老师必须 / 不能教同一年级」
  • 「如果……就……」这类条件要求
  • 「某类班每周加一节某课」—— 请改在「课时标准」表的「非选考周课时」里填数字

普通说明文字（如「年级：高二」「2026年秋季作息」）不影响排课，也不会误报。

课表上的学科按标准名显示：信息 / 心理 / 体育 / 艺术 （「信息课」「信息技术」「计算机」都会按「信息」处理；「心理健康」按「心理」）。

不会写？用 AI 帮你转成结构化写法

三步：

  1. 点「生成提示词」——软件会把你写的要求里教师姓名 / 班级名自动换成编号 （不泄露姓名），并附上你表里的教师、班级清单；
  2. 在下面的框里全选复制，发给任意 AI（豆包、文心一言、Kimi 等都可以）；
  3. 把 AI 返回的 JSON 整段粘回上面的输入框（连 ```json 那几行一起）， 再点「开始排课」。
