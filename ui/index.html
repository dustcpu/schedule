输入文件要求

请上传包含以下三个 sheet 的 .xlsx 文件：

  • 教师：教师ID、教师姓名、任教学科、职务（只需填语数英、物化生政史地等参与排课的教师，体育/艺术无需填写）
  • 班级：班级ID、班级名称、年级、班主任、选科（如物化生、政史地）
  • 课时标准：学科、选考周课时、非选考周课时、连堂节数、连堂日

系统根据班级选科 + 课时标准自动生成每门课的周课时，并按教师工作量均衡自动分配任课教师。如需特殊指定（如某某老师教尖子班），可在下方「特殊要求」中输入，格式：教师ID教班级ID学科（如 T30教C05英语）。体育活动为每天第9节固定附加，不参与排课。

选好输入文件后，这里会用**你表里真实的**教师ID、班级ID举例。

✔ 支持的写法：指定某位老师教某个班的某个学科

  • 教师ID + 教 + 班级ID + 学科 —— 例如 T30教C05英语
  • 用等号写效果一样：T30=C05英语
  • 也可以写教师姓名 + 班级名称：张老师教高二(1)班英语
  • 每行一条；行首编号写不写都行（1.T30教C05英语 一样能识别）
  • ⚠️ ID 照抄「教师」「班级」表里的写法：表里是 T30 就写 T30， 不要自己补成 T030（补零的写法现在也能认，但以表里为准最稳）

✘ 暂不支持（写了会提示"这条没生效"，不会排进课表）：

  • 「某老师教的班里必须包含某个班」—— 如：教师T30所教的班级里必须有一个是C05
  • 「某位老师最多/最少带几个班」这类数量限制
  • 「某类班每周加一节某课」—— 请改在「课时标准」表的「非选考周课时」里填数字

普通说明文字（如「年级：高二」「2026年秋季作息」）不影响排课，也不会误报。

课表上的学科按标准名显示：信息 / 心理 / 体育 / 艺术 （「信息课」「信息技术」「计算机」都会按「信息」处理；「心理健康」按「心理」）。
