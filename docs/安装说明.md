# 排课助手 - 团队编译说明

## 一、这是什么

排课助手是一个 Win11 桌面软件外壳（UI + 文件交互），用 **Tauri 2（Rust + 原生 HTML/JS）** 写。
算法/排课引擎是独立的 Python 程序，打包成 `engine.exe` 后由外壳调用（sidecar 模式）。

```
排课助手.exe（外壳）
   └── 调用 engine.exe（算法）
          ├── 读 input.xlsx + requirements.txt
          └── 输出 result.xlsx + result.pdf + status.json
```


## 三、环境准备（只做一次）

### 1. Rust 工具链
- 安装 [rustup](https://rustup.rs/)，或用项目里已有的 workbuddy 独立 Rust
- 确认 `cargo --version` 能跑

### 2. Node.js（Tauri 需要）
- 装 Node.js 18+（https://nodejs.org/）
- 确认 `node --version` 能跑

### 3. Python（跑引擎用）
- 装 Python 3.10+
- 装依赖：
  ```
  pip install reportlab openpyxl
  ```

### 4. Tauri CLI（可选）
```
cargo install tauri-cli --version "^2.0"
```

## 四、开发模式（跑起来看效果）

```
cd src-tauri
cargo run
```

或者双击根目录的 `启动-开发.bat`。

开发模式下，引擎会找 `../engine/mock_engine.py` 用 Python 直接跑（不需要打包）。

## 五、打包成 exe（发布用）

```
cd src-tauri
cargo tauri build
```

产物在：`src-tauri/target/release/排课助手.exe`

**注意**：打包前把真正的算法引擎放到 `src-tauri/resources/engine/engine.exe`（开发阶段用 mock_engine.py 就行）。

## 六、算法同学看这里

请严格按照 `接口协议.md` 实现 `engine.exe`：
- 输入：一个目录，里面有 `input.xlsx` 和 `requirements.txt`
- 输出：同目录下生成 `result.xlsx`（多 sheet）、`result.pdf`（多页）、`status.json`（含 plans 数组，3-8 套多解）
- 命令行：`engine.exe <输入目录> <输出目录> <任务ID>`

外壳会自动调用你，不用关心 UI。

## 七、常见问题

**Q: 编译报错找不到 tauri？**
A: 确认 `cargo` 在 PATH 里，且在 `src-tauri/` 目录下运行命令。

**Q: 打包后引擎找不到？**
A: 开发模式用 `engine/mock_engine.py`；发布模式需要把 `engine.exe` 放到 `src-tauri/resources/engine/`。

**Q: PDF 中文乱码？**
A: reportlab 用系统字体（微软雅黑 msyh.ttc），Windows 自带，不用额外装。
