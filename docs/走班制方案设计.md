# 走班制排课方案设计

> **状态：设计稿，未实现。** 本文只回答问题"走班要怎么接进现在这套引擎"，
> 不含任何代码改动。落地前需要先定 §7 的几件事。
>
> 关联：`docs/排课约束目录.md` §0（走班范围口径）、§2（列为 v2）、§11（待澄清问题）；
> `docs/接口协议.md`（输入数据契约）。

---

## 1. 先说结论

现在是**纯行政班模型**：一门课 = 「一个行政班 + 一个学科」，一节课占满全班。
走班意味着「同一节课里，一个班的学生被拆到不同的教学班」，**学生个体第一次进入模型**——
这不是加几条约束，而是数据契约 + 建模 + 导出 + 校验四层都要动。

建议按**三阶段**推进，每阶段都能独立交付、独立验收：

| 阶段 | 范围 | 需要学生名单？ | 改动量 |
|---|---|---|---|
| **A** | 体育 / 艺术**按班分组**走班 | 否 | 中 |
| **B** | 体育 / 艺术**学生自由选项目** | 是 | 大 |
| **C** | 选考科目（物化生政史地）分层走班 | 是 | 很大 |
| D | 全学科全走班 | 是 | 不建议 |

**建议先做 A**：它覆盖了 §0「仅体育/艺术走班」口径下的大多数真实场景，
且**不需要学生名单**——只加两张表、不动学生级模型。

---

## 2. 为什么现在的模型做不了

| 位置 | 现状 | 走班要求 |
|---|---|---|
| 决策变量 | `x[(班级, 学科, 天, 节)]`：一格代表"整个班上这门课" | 一格代表"这个班的学生去各自的**教学班**" |
| H1 每格唯一 | 每班每格恰好一门课（`AddExactlyOne`） | 走班时段**整组所有班**必须同时在上同一走班学科 |
| H3 教师冲突 | 教师由 `y[班级,学科,教师]` 决定，取 `z = x AND y` | 教学班各有自己的教师，且**同组内可并行** |
| 课表导出 | 行=班级、列=节次，格子里写学科 | 需要能回答"**这个学生**这节上什么" |
| 校验 | 按班级维度逐格查 | 需按学生/教学班维度查 |

关键难点：**一个时段里，同一个班的不同学生去不同教室**。现有模型没有任何
"学生"这个实体，所以走班不是补约束，而是补一层数据。

---

## 3. 两种走班形态，成本差一个量级

### 3.1 按班分组（整体走班）

把若干行政班编成一个**走班组**，体育课就按组分班上课（如 1、2、3 班合成一个大组，
分 3 个教学班上体育）。**同一组内全班同学去同一个教学班**，学生之间没有拆分。

- 需要：走班组、教学班两张表
- 不需要：学生名单、H11 学生不冲堂
- 建模：组级同步（H7）+ 教学班容量（H22，按班人数推算即可）

### 3.2 学生自由选项目（真·走班）

学生各自选不同项目（篮球/足球/羽毛球…），同一班的人散到不同教学班。

- 需要：**学生级选科名单**（每班每生一行，或"班级×项目→人数"矩阵）
- 需要：H11 学生不冲堂
- 规模：25 班 × 50 人 ≈ 1250 个学生实体；若走班科目多，约束规模会显著上去

> ⚠️ 只要学生名单进来，"隐私红线"就要重新审一遍：名单含**学生姓名/学号**。
> 现有约定是真实数据不入库、不外发（提示词脱敏也只处理教师/班级）。
> 学生名单要么只进本地输入目录、要么用学号占位，**绝不能进仓库**。

## 4. 数据契约（阶段 A）

沿用"一个 xlsx 多个 sheet"的既有约定，新增两张（旧文件不加也能跑，走班功能整体关闭）：

### 4.1 `走班组`（可选 sheet）

| 列 | 必填 | 说明 |
|---|---|---|
| 走班组ID | ✓ | 如 `G01` |
| 走班组名称 | | 如 `高二体育一组` |
| 学科 | ✓ | `体育` / `艺术` |
| 成员班级 | ✓ | 行政班ID，多个用 `,` 或 `、` 分隔，如 `C01,C02,C03` |
| 年级 | | 用于分组校验 |

### 4.2 `教学班`（可选 sheet）

| 列 | 必填 | 说明 |
|---|---|---|
| 教学班ID | ✓ | 如 `TC0101` |
| 所属走班组 | ✓ | 外键 → `走班组.走班组ID` |
| 层级/项目 | | 如 `篮球` / `A层`；按班分组时留空 |
| 任课教师 | | 教师ID（阶段 A 可空，体育/艺术现在不显示教师） |
| 周课时 | ✓ | 该教学班每周几节 |
| 场地 | | 阶段 A 只登记，不参与 H3 场地约束 |

**校验（进现有的预检/加载校验）**：成员班级必须存在；同一成员班不得出现在
同一学科的两个走班组里；教学班周课时之和须等于课时标准里该学科对成员班的周课时；
组成员班的选科/年级一致性只做**警告**不做拒绝。

### 4.3 `学生选科名单`（阶段 B 才需要，可选）

`学生ID | 行政班 | 走班组 | 教学班`，一人一行。**建议用学号占位**，不要姓名。

## 5. 建模设计（阶段 A）

在现有 `x / y / z` 之上加**一层组级变量**，不改动原有约束。

### 5.1 组级同步（H7）

对每个走班组 `G`（学科 S、成员班集合 M、教学班集合 T）：

- 新增 `g[(G, d, per)]`：1 = 该组此刻在走上班课
- `Σ_g ≤ 1`（同一时段一组最多一节走班课）
- 对每个成员班 `c ∈ M`：`x[(c, S, d, per)] == g[(G, d, per)]`
  → 这一步**白拿**了 H1：走班时段该班这一格必然被 S 占住，别的科目进不来
- 教学班层：`Σ_{tc ∈ T} tcs[(tc, d, per)] == g[(G, d, per)] × |T|`，
  即整组同步——要么全上、要么都不上（这正是 H7 的字面含义）

教师与场地冲突复用现有 `z = x AND y` 的写法，作用在教学班维度即可，**不需要新机制**。

### 5.2 容量（H22）

阶段 A 可以直接用**成员班人数**推算：每个教学班覆盖的行政班人数之和 ≤ 容量上限
（容量做成可配置，默认 50）。不需要学生个体。

### 5.3 周课时（H2 的延伸）

走班课的周课时记在**教学班**上而不是行政班上：把现有 `req[(班级, 学科)]`
在走班学科上改成对 `g` 计数，行政班维度只保留"占位"语义。

### 5.4 明确不做（阶段 A）

- H11 学生不冲堂（按班分组时天然满足：一个班只去一个教学班）
- 场地/器材冲突（H3/H18）——先登记场地不校验

## 6. 导出与展示（容易被低估的一块）

教务最终要看的还是**行政班课表**。走班时段那一格建议显示为：

```
体育（篮球）
```

即"学科（层级/项目）"，并在表尾附一张**教学班明细表**（教学班 / 教师 / 场地 / 时段）。
若要给学生视角，再加一张"按教学班排的课表"。

`verify_hard.py` 相应增加复核项：

- **H7**：同组教学班的时段集合完全一致
- **H22**：各教学班的推算人数 ≤ 上限

## 7. 落地前需要拍板的几件事

沿用 `docs/排课约束目录.md` §11，走班相关的三条仍未定，加上本次新暴露的：

| # | 问题 | 影响 |
|---|---|---|
| 1 | 体育/艺术是**按班分组**还是**学生自由选项目**？ | 决定做阶段 A 还是 B，成本差一个量级 |
| 2 | 整年级一起走，还是几个班一组？ | 决定 `走班组` 粒度与同时段能开几个组（教师/场地是否够） |
| 3 | 体育场地能同时容纳几个班？ | H22 的容量上限取值 |
| 4 | 走班课在课表上怎么显示？（学科 / 学科+项目 / 学生个人课表） | 导出层改动量 |
| 5 | 教学班的层级/项目由谁定、怎么命名？ | `教学班` 表字段语义 |
| 6 | 音乐/美术是否也走班，还是只有体育？ | 走班学科清单 |

**建议**：先拿一所学校的**真实分组方式**跑一遍阶段 A 的小样（3 个班、1 门体育），
确认上面 1/2/3/4 都定了，再决定要不要做阶段 B。

## 8. 与"特殊要求 AI 转 JSON"的关系

现有结构化约束的 5 个 type（`assign_teacher` / `teacher_unavailable` /
`teacher_no_double_day` / `class_unavailable` / `teacher_max_classes`）**都不涉及走班**。

走班落地后可以追加两类，仍然走同一条通道（围栏块 / `structured_requirements.json`）：

- `group_unavailable`：某走班组某天/某节不排走班课
- `assign_homeroom_group`：指定某班在某走班组中的教学班

**不需要现在动提示词**——等走班的数据契约定了，再一次性加 type 与词典触发词，
避免现在就把 AI 的枚举值撑大（枚举越大越容易幻觉）。

## 9. 风险

1. **成本低估**：真正的大头不是建模，而是数据契约 + 导出 + 校验 + 界面模板，
   约占七成工作量。
2. **求解释放变慢**：组级变量把"按班独立"的结构变成"按组同步"，剪枝变弱；
   25 班规模下体育/艺术占课时少，预计可接受，但需实测。
3. **学生数据合规**：阶段 B 一开始就会引入学生名单，必须守住"只落本地、不入库"。
4. **与已有约束打架**：走班时段的固定课（班会、研究性学习）若落在同一格，
   会直接无解。需在预检阶段就报出来，而不是让用户等三分钟。
