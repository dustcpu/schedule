## 1. 本校走班的实际形态

### 1.1 是什么

**分裂型走班**：同一个行政班的学生，同一节课去不同教室上课。

但它的实际机制不是"班内临时分成两拨"，而是：

> **全年级按选考科目重新编班；教学班是跨行政班拼出来的。**

一个教学班由多个行政班的部分学生组成，例如（示意，非真实数据）：

| 教学班 | 来源 | 合计 | 教室 |
|---|---|---|---|
| 政治教学班 | A 班「历政地」29 人 ＋ A 班「历政生」10 人 ＋ C 班「物化政」3 人 | 42 人 | A 班教室 |
| 地理教学班 | A 班「历生地」2 人 ＋ D 班「物化地」55 人 | 57 人 | D 班教室 |
| 化学教学班 | A 班 2 种组合 4 人 ＋ E 班 2 种组合 55 人 | 59 人 | E 班教室 |

**同一个走班时段里，这些教学班同时开课**，学生按自己选的科目走。

### 1.2 三个关键特征

| # | 特征 | 含义 |
|---|---|---|
| 1 | **只在部分班级发生** | 不是全部行政班都走班，取决于各班的选科组合分布 |
| 2 | **只涉及小四科** | 政治 / 生物 / 地理 / 化学；语数英等不参与 |
| 3 | **由「独立时间」承载** | 走班不挤进常规课的排法，而是若干次专门时段；**每次两节连排** |

### 1.3 为什么**不需要学生名单**（对初版的修正）

组班方案由教务制定（要综合人数、成绩、教室等因素），**程序只需照单排时段**。因此：

- ❌ 不需要学生姓名 / 学号
- ❌ 不需要"每个学生属于哪个教学班"
- ✅ 只需要「教学班」这张表（含来源班级、人数、教室、教师）

> ⚠️ 这条修正很关键：初版把"要不要学生名单"当成走班成本的分界线，
> 于是把这件事判成"很大改动"。实际上只要有**教学班划分**，
> 排课环节完全不需要个体学生数据。
> （"给学生打印个人课表"是独立话题，不在本期范围。）

## 2. 数据契约：教务要提供什么

沿用"一个 xlsx 多个 sheet"的既有约定。走班新增两张 sheet；
**旧文件不带这两张表也能照常跑**（走班功能整体关闭）。

### 2.1 `走班教学班`（可选 sheet）

| 列 | 必填 | 说明 |
|---|---|---|
| 教学班ID | ✓ | 如 `TC01`。校方若已有命名（如"政治走班1"）可直接沿用 |
| 独立时间 | ✓ | 外键 → `走班时间.独立时间ID`；同组必须**同时开课** |
| 学科 | ✓ | 政治 / 生物 / 地理 / 化学 |
| 来源班级 | ✓ | 行政班ID（如 `C03`）；一个教学班可能有多行来源 |
| 选考组合 | | 该来源对应的选考组合，仅用于核对与告警，不参与求解 |
| 人数 | | 该来源的人数，仅用于核对与告警，不参与求解 |
| 教室 | | 教室名/编号。程序只登记与输出，**不做容量校验** |
| 任课教师 | | 教师ID；**留空则由引擎分配**（与现有 `y` 变量一致） |

**预检规则**（进现有的输入预检，逐条独立报告，坏的只丢该条）：
- 来源班级必须存在
- 同一教学班各来源人数之和 = 教学班总人数（不一致 → 警告）
- **同一独立时间内，任课教师不得重复**（否则该时段必然冲突）
- 同一独立时间内，两个教学班共用同一间教室 → 警告

### 2.2 `走班时间`（可选 sheet）

| 列 | 必填 | 说明 |
|---|---|---|
| 独立时间ID | ✓ | 如 `T1` |
| 周次数 | ✓ | 该独立时间每周开几次 |
| 连排节数 | | 默认 **2** |
| 参与班级 | ✓ | 哪些行政班在这个时段走班（未列出的班此时上常规课） |

> 若校方课表里走班时段是固定的（例如固定在每周某几天的特定两节），
> 可以把这些位置登记进现有设置页的**不可用时段**，让求解器绕开；
> 但**不建议把节次硬编码进引擎**——保持"由求解器选时段"更灵活。

## 3. 建模设计

在现有 `x / y / z` 之上加**一层独立时间变量**，**不改动任何现有约束**。

### 3.1 变量

- `g[(T, d, per)]`：独立时间 `T` 是否落在第 `d` 天第 `per` 节（0/1）

### 3.2 约束（编号接现有 H29 之后）

| 编号 | 含义 | 要点 |
|---|---|---|
| **H30** | 独立时间落位 | 每个 `T` 每周落且仅落 `周次数 × 连排节数` 个节次；连排则须落在**相邻**两节 |
| **H31** | 组内同时开课 | `T` 内每个教学班的开课变量与 `g[T]` 绑定：`g[T,d,per]=1` ⇒ 该组各教学班在 (d,per) 全部开课 |
| **H32** | 参与班让位 | `T` 落在 (d,per) 时，参与该 `T` 的行政班在 (d,per) **不排常规课** |
| **H33** | 教师不冲突 | 各教学班的任课教师在该时段只出现在一个教学班（复用现有 `z = x AND y` 的写法） |
| **H34** | 走班课时计入 | 走班学科的周课时记在**教学班**上；行政班维度只保留"占位"语义，避免重复计数 |

> **要点**：走班时段里，H1（每格唯一）要按**教学班**维度理解，而不是行政班维度——
> 同一个行政班在同一格有多个教学班并行，这正是走班的定义，不是冲突。

### 3.3 明确不做

- ❌ 教室容量校验（校方确认座位充足）
- ❌ 自动分组（组班是教务决策）
- ❌ 学生个人课表

## 4. 输出（课表）

**输出形态对齐校方现有课表**，教务拿到可直接使用：

- 主表：**行 = 天 × 节次，列 = 每个行政班一列**，右侧附**走班教室列**
- 走班格写**多行**「学科 ＋ 去向」：
  ```
  地理（本班）
  生物 → 走班2 教室
  政治 → 24班教室
  ```
- 走班时段用**颜色标记**（校方现用两种颜色区分走班的第一节 / 第二节）
- 另附一张**教学班明细表**：教学班 / 学科 / 来源 / 人数 / 教室 / 教师 / 时段

`verify_hard.py` 相应增加复核项：
- **H31**：同组教学班所在时段完全一致
- **H32**：走班时段内，参与班没有常规课
- **H33**：同一时段各教学班教师互不重复

## 5. 风险

1. **成本大头不在建模**（约三成），而在**数据契约 + 输出改版 + 校验**（约七成）。
2. **求解释放可能变慢**：组内同步约束会削弱"按班独立"的剪枝结构。走班课时占比不高时预计可接受，需实测。
3. **与既有约束打架**：走班时段若与固定课（班会 / 研究性学习 / 校本课）落在同一格，会直接无解。
   必须在**预检阶段**就报出来，而不是让用户等几分钟。
4. **校方数据写法不规范**：教学班的"来源"可能一行多个、命名各异。
   解析要宽松，**逐条告警但只丢该条**，绝不静默。

## 6. 建议的下一步

1. 确认 **§2 的两张 sheet 是否够用**（承载校方现有的走班方案）；
2. 拿**一个独立时间**的小样（几个班、两三种组合）做建模验证，先不管输出；
3. 确认求解时间可接受后，再动输出与界面；
4. 界面上给一个**走班开关**（默认关），关着时行为与现在完全一致。
