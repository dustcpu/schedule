# 约束能力清单（特殊要求 → 结构化约束 → 引擎）

> **版本**：schema v1（2026-10-03）
> **定位**：《额外约束处理方案评估》§7 第 0 步的起步交付物，**一份三用**：
> ① 给教务的写法对照表；② 给程序的 JSON schema（引擎 `structured_requirements.json`
> / 围栏块的唯一机器接口）；③ 词典触发词表（语料收集与覆盖率测量的底账）。
> **维护规则**：新增约束类型必须三处同步——本清单、`engine/scheduler/data/load.py`
> 的 `_validate_structured_item`、`约束转换器/词典.py` 的解析规则；编号遵守
> 《排课约束目录》"只追加不改号"。

---

## 0. 怎么用

- **教务**：看 §1 对照表，照着写自然语言，交给约束转换器
  （`约束转换器/nl2req.py`）转换；或直接用软件「特殊要求」框的现有文本写法。
- **程序**：§2 的 JSON 是唯一机器接口。转换器产出的
  `structured_requirements.json` 放进输入目录，或把 ```json 围栏块粘进
  「特殊要求」框，两者等效。
- **团队**：§3 的触发词表是词典的现状；收集到教务真实说法后跑
  覆盖率测量（>90% 不上模型，见《额外约束处理方案评估》§0）。

## 1. 写法对照表（给教务）

| # | 想要什么 | 自然语言示例（转换器可解析） | 生成的 JSON | 引擎约束编号 |
|---|---|---|---|---|
| 1 | 指定某老师教某班某科 | `T30教C05数学`、`张卫东教高二(1)班物理` | `{"type":"assign_teacher","teacher":"T30","class":"C05","subject":"数学"}` | 已有（教师指定语义） |
| 2 | 某老师某天/某节不上课 | `张卫东周二没空`、`李梅周四下午不排课`、`T045周五第1-2节请假` | `{"type":"teacher_unavailable","teacher":"T077","days":[2]}`（periods 省略=全天） | H4 教师不可排时段 |
| 3 | 某老师不想周X上连堂 | `张卫东不想周二上连堂` | `{"type":"teacher_no_double_day","teacher":"T077","days":[2]}` | H28 教师连堂禁日 |
| 4 | 某班某天/某节不排课 | `C01班周五第7-8节不排课`、`高二(5)班周一上午安排活动` | `{"type":"class_unavailable","class":"C01","day":5,"periods":[7,8]}`（periods 省略=全天） | H27 班级不可排时段 |
| 5 | 某老师最多带几个班 | `张卫东最多带2个班` | `{"type":"teacher_max_classes","teacher":"T077","max":2}` | H26 的用户可配形态 |

**必读的口径说明**：

- 星期：周一~周五（1-5）；节次：1-8（上午 1-5、下午 6-8）；一个班每天最多 8 节。
- 「周X不排连堂」的**实际语义**：连堂日按学科固定（数学周二/语文周三/英语周四），
  禁掉那天 = 该老师**不担任该学科任课**。转换器与引擎都会预警这一点；
  例：数学老师不想周二上连堂 ⇒ 他不能教数学 ⇒ 若教师数本就贴着下限（25 班需 13 位）
  会直接报"无人可任课"。
- 「某班不排课」的格子会**显示为自习**（课表必须满格）。
- 转换器认不出的行**明确说认不出**，绝不硬猜；可走 AI 提示词人工兜底
  （姓名自动脱敏为编号），AI 返回的 JSON 必须经 `nl2req.py --validate` 校验。
- 已知暂不支持（评估文档 C 类，需新建模）：「某老师带的班里必须包含某班」、
  「两位老师必须/不能同年级」、条件约束（如果…则…）。

## 2. JSON Schema v1（给程序）

```json
{
  "version": 1,
  "constraints": [
    {"type": "assign_teacher",       "teacher": "T30", "class": "C05", "subject": "数学"},
    {"type": "teacher_unavailable",  "teacher": "T30", "days": [2], "periods": [6, 7, 8]},
    {"type": "teacher_no_double_day","teacher": "T30", "days": [2]},
    {"type": "class_unavailable",    "class": "C01", "day": 5, "periods": [7, 8]},
    {"type": "teacher_max_classes",  "teacher": "T30", "max": 2}
  ]
}
```

**引擎侧校验规则**（`engine/scheduler/data/load.py`）：

- `version` 必须为 1，否则整块忽略并告警；
- `type` 不在白名单 → 只丢弃该条并告警（宁可弃权，不要猜）；
- `days`：1-5 的整数或数组；`class_unavailable.day` 是单数（一天一条，多天拆多条）；
- `periods`：1-8 的数组，**省略 = 全天**；
- `teacher`/`class` 必须能在 input.xlsx 的对应表里找到（容忍 T030↔T30 补零差异）；
- 每条独立校验、独立生效，坏一条不牵连其他；生效后逐条回显进 `warnings`。

**引擎侧实现落点**：

| 类型 | 实现位置 | 机制 |
|---|---|---|
| assign_teacher | `load.py` 教师指定管道 | 收缩候选为 1 人并锁定（与文本写法同源） |
| teacher_unavailable | `model.py` 结构化段 | `x[(班,科,天,节)] + y[(班,科,师)] ≤ 1`（H4 落地） |
| teacher_no_double_day | `load.py` `apply_structured_double_bans` | 从候选集移除（连堂日固定 ⇒ 禁日=禁整科；模型层 b+y≤1 会与 H26 下界相撞，见该函数注释） |
| class_unavailable | `model.py` 结构化段 | 禁排格除自习外全部 `x==0`，格子由自习填充 |
| teacher_max_classes | `model.py` 结构化段 | `sum(y) ≤ max`，叠加在 H26 自动推导的上下界之上 |

**校验器**：`engine/verify_hard.py` 对以上四类逐一复核结果课表（跑通 ≠ 正确）。

## 3. 词典触发词表（给团队 / 语料收集）

转换器词典（`约束转换器/词典.py`）当前能命中的说法族：

| 类型 | 触发要素 | 已覆盖说法 |
|---|---|---|
| 指定任课 | 教师 + `教`/`=` + 班级 + 学科 | `T30教C05数学`、`T30=C05数学`、`张卫东教高二(1)班物理`、行首编号可省 |
| 教师不可用 | 教师 + 星期 + （不上课/不排课/不上/不排/不想上/没空/没时间/请假/有事/不在/休息/别安排/外出/教研/调休）+ 可选（上午/下午/第N-M节） | 整天、半天、单节、区间 |
| 教师连堂禁日 | 教师 + 星期 + 连堂/连排/连着/两节连/双节 + 否定（不想/不要/别/避免/避开/禁止/不安排/不来/不希望） | `不想周二上连堂`、`连堂避开周五` |
| 班级不可用 | 班级 + 星期 + （不排课/不上课/不安排课/留空/空着/安排活动/搞活动/考试/测验/大扫除等）+ 可选节次 | 多天自动拆条；「每班/各班」泛指不误收 |
| 带班上限 | 教师 + （最多/至多/不能超过/不超过/上限是）+ 数字 + 个班 | 汉字数字可解析 |

**尚未覆盖的高频说法**（收集语料时重点验证，逐条决定进词典还是归入"暂不支持"）：
「某老师只有周X有空」（正向表述）、「某两科不要同一天」、「某班某科要连堂」（非语数英）、
「某老师上午的课尽量多」（软偏好——v1 全部按硬约束处理，软偏好暂不入）。

**覆盖率测量流程**：真实说法（脱敏后）存入 `约束转换器/测试语料/` →
`nl2req.py --text … --xlsx …` → 统计命中行 / 总行数 → 按《额外约束处理方案评估》§0
的 90% 线决定是否需要本地模型。
