# input.xlsx 模板及字段说明（新格式）

> 接口协议 §10 要求算法团队交付「`input.xlsx` 模板及字段说明」，本文档即该交付物。
> 外壳不解析 xlsx 内部结构（协议 §3），故本文件是**教务老师填表**与**内核读数**之间的唯一约定。
>
> 生成测试文件：`python make_sample_input.py sample_input.xlsx 4`
>
> ⚠️ 旧的 3-sheet 格式（班级 / 教师 / 课程）**已不再支持**，
> 检测到会直接报 `code=2`：「检测到旧格式输入…请改用新格式」，不会再静默兼容。

---

## 为什么要用新格式

旧格式要求逐班逐科填 250 行（25 个班 × 10 门课），容易漏填、口径也容易不一致。
新格式只需要**填一张 15 行的学科标准表**，系统按各班「选科」自动展开成 250 条课程：

```
课时标准（15 行） × 班级选科  →  自动展开  →  每班的课程需求
      ↑                                              ↑
  教务处填一次                                  引擎自己算
```

---

## Sheet 1「教师」

| 列名 | 必填 | 说明 |
|---|---|---|
| 教师ID | ✅ | 教师唯一标识，如 `T001`。**建议用编号而非真实姓名**（团队约定：内部文档不写真实姓名） |
| 教师姓名 | 可选 | 展示用；留空则显示教师ID |
| 任教学科 | ✅ | 决定该教师能教什么，如 语文 / 物理 / 体育 |
| 职务 | 可选 | 备注用，如「班主任」，当前不参与排课决策 |

## Sheet 2「班级」

| 列名 | 必填 | 说明 |
|---|---|---|
| 班级ID | ✅ | 班级唯一标识，如 `C01`。内核以此为主键，禁止重复 |
| 班级名称 | 可选 | 展示用，如「高二(1)班」；留空则显示班级ID |
| 年级 | 可选 | 如「高二」 |
| 班主任 | 可选 | 备注用，当前不参与排课决策 |
| 选科 | ✅ | 该班的三门选考科目，如 `物化生`、`政史地`。**字符须取自 物/化/生/政/史/地** |

## Sheet 3「课时标准」（核心）

每行 = 某门学科的周课时标准，对**所有班级**生效。系统再按各班的「选科」决定某学科走
「选考周课时」还是「非选考周课时」。

| 列名 | 必填 | 说明 |
|---|---|---|
| 学科 | ✅ | 如 语文 / 数学 / 英语 / 物理 / 化学 / 生物 / 政治 / 历史 / 地理 / 体育 / 艺术 / 班会 |
| 选考周课时 | ✅ | 该学科**是本班选考科目**时的周节数；填 `0` 表示该组合不开这门课 |
| 非选考周课时 | ✅ | 该学科**不是本班选考科目**时的周节数；通常填 `0` |
| 连堂节数 | 可选 | `0`（默认，不连堂）或 `2`（两节连堂）。**只有语数英的连堂会生效**，其他学科填了会被自动取消并在 warnings 中提示 |
| 连堂日 | 可选 | `1`–`5`（周一–周五）。⚠️ **当前版本该列尚未生效**，连堂日取外壳设置（默认：数学周二、语文周三、英语周四），详见下方「已知限制」 |

## Sheet 4「任课安排」（可选，可以整张表不存在）

不填这张表时，引擎会按学科与工作量自动为每门课生成 3 位候选教师，
**在排课的同时决定最终任课**（每门课恰好 1 位教师），但不保证方案之间任课一致。

| 列名 | 必填 | 说明 |
|---|---|---|
| 教师ID | ✅ | 必须是「教师」表里的教师 |
| 班级ID | ✅ | 必须是「班级」表里的班级 |
| 学科 | 可选 | 留空则用该教师的「任教学科」 |

> 体育 / 艺术 / 音乐 / 美术 / 信息技术 / 通用技术 / 心理 / 班会 / 研究性学习 / 校本课 / 自习
> 这几门**不需要指定教师**，即使填了也会被忽略。

## 硬性校验规则（不满足则 code=2 并在 message 说明）

1. 「班级」「教师」「课时标准」三张表必填，缺任一张即报错；「任课安排」可选。
2. 「班级」表的班级ID 不能重复；「课时标准」表的学科不能重复。
3. **每班周课时之和 ≤ 40**（8 节 × 5 天）。超过会报错并提示该班合计多少。
   - 校验器按「选科」展开后逐班核算，不是只看单个学科的数字。
4. 连堂学科的周课时必须 ≥ 连堂节数 × 每天块数，否则报错。
5. 「任课安排」里出现教师表/班级表里没有的 ID，只给 warning，不阻断。

## 自习

**推荐做法**：不给「自习」填行。内核会用剩余格子自动补齐
（`自习周课时 = 40 − 其他学科课时之和`）。
也可以显式在课时标准里写一行 `学科=自习` 指定节数。

## 固定课与连堂（来自外壳设置页 / hard_limits.json）

这两项**不在 input.xlsx 里填**，由外壳的「设置」页维护并写入 `hard_limits.json` 传给内核；
若外壳未传，内核使用与外壳一致的默认值：

| 项 | 默认值 |
|---|---|
| 作息 | 8 节/天，40 分钟/节，08:00 上学，上午 5 节至 12:20，下午 14:30 起至 16:55；第 3 节后大课间 30 分钟，第 6 节后眼操 15 分钟 |
| 固定课 | 周一第 1 节 班会；周一第 8 节 研究性学习；周四第 8 节 校本课 |
| 连堂 | 数学（周二）、语文（周三）、英语（周四），每班每天 1 个 2 节连堂块。**连堂只能落在【1-2 节】或【4-5 节】**（不允许 2-3、3-4 等中间位置） |

## 最小示例（4 个班）

`python make_sample_input.py sample_input.xlsx 4` 会产出可直接排课的样例：

- **教师**：语文×2、数学×2、英语×2、物理/化学/生物/政治/历史/地理/体育/艺术 各 1，共 14 位
- **班级**：C01–C04，选科依次为 物化生 / 物化地 / 政史地 / 史地生
- **课时标准**：语文 6（连堂 2 节）、数学 6（连堂 2 节）、英语 6（连堂 2 节）、
  物理 5、化学/生物/政治/历史/地理 各 4、体育 2、艺术/班会/研究性学习/校本课 各 1
- **故意不含「任课安排」**，用来覆盖「引擎自动决定任课」这条路径

各班周课时合计 36–37 节，剩余由内核自动补为自习。

## 已知限制

1. **「连堂日」列尚未生效。** 引擎当前从 `hard_limits.json` 取连堂日
   （`config.ConsecutiveRule.day_of()`，默认 数学=周二 / 语文=周三 / 英语=周四），
   课时标准里填的「连堂日」会被解析但**不被使用**。
   样例数据恰好填了 2/3/4，与默认值一致，所以看不出来。
2. **「自习」不参与课时标准展开**，只能靠剩余格子自动补齐或显式占位。
3. **不支持单双周**。旧格式的「单双周」列已随旧格式一并移除，v1 内核只排「每周」。
