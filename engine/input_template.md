# input.xlsx 模板及字段说明

> 接口协议 §10 要求算法团队交付「`input.xlsx` 模板及字段说明」，本文档即该交付物。
> 外壳不解析 xlsx 内部结构（协议 §3），故本文件是**教务老师填表**与**内核读数**之间的唯一约定。
> 生成测试文件：`python make_sample_input.py sample_input.xlsx 4`

---

## Sheet 1「班级」

| 列名 | 必填 | 说明 |
|---|---|---|
| 班级ID | ✅ | 班级唯一标识，如 `C01`。内核以此为主键，禁止重复 |
| 班级名称 | 可选 | 展示用，如「高二(1)班」；留空则显示班级ID |
| 年级 | 可选 | 如「高二」 |
| 科类 | 可选 | 文科 / 理科（分科用） |

至少 1 行。

## Sheet 2「教师」

| 列名 | 必填 | 说明 |
|---|---|---|
| 教师ID | ✅ | 教师唯一标识，如 `T01`。**建议用编号而非真实姓名**（团队约定：内部文档不写真实姓名） |
| 教师姓名 | 可选 | 展示用；留空则显示教师ID |
| 任教学科 | 可选 | 备注用，内核以「课程」表的绑定为准 |

## Sheet 3「课程」（核心）

每行 = 某个班的某一门学科的课时需求。**(班级ID, 学科) 必须唯一，不能重复行。**

| 列名 | 必填 | 说明 |
|---|---|---|
| 班级ID | ✅ | 必须与「班级」表对齐 |
| 学科 | ✅ | 如 语文 / 数学 / 英语 / 物理 / 化学 / 生物 / 体育 / 自习 |
| 教师ID | 可选 | 该班该科的任课教师。**留空 = 无固定教师**（班会、自习等），不参与教师冲突约束 |
| 周课时 | ✅ | 每周节数，**必须为正整数** |
| 连堂节数 | 可选 | `0`（默认，不连堂）或 `2`（两节连堂）。连堂学科还需在硬限制里配置连堂日 |
| 单双周 | 可选 | `每周`（默认）/ `单周` / `双周`。**v1 内核暂按每周排课**，若填单/双周会在 status.json 的 warnings 中如实提示（待团队拍板 R5 后启用周维度） |

## 硬性校验规则（不满足则 code=2 并在 message 说明）

1. 同一班级同一学科只能出现一行，重复即报错。
2. 「课程」表的班级ID 必须在「班级」表中存在。
3. 周课时必须 > 0。
4. **每班所有学科的周课时之和 ≤ 40**（8 节 × 5 天）。超过会报错提示减少课时。
5. 连堂学科的周课时必须 ≥ 连堂节数 × 每天块数，否则报错。

## 自习

- **推荐做法**：不给「自习」填行，内核会自动用剩余格子补齐（`周课时 = 40 - 其他学科课时之和`）。
- 也可显式写一行 `学科=自习`，指定自习节数（教师ID 留空）。

## 固定课与连堂（来自外壳设置页 / hard_limits.json）

这两项**不在 input.xlsx 里填**，由外壳的「设置」页维护并写入 `hard_limits.json` 传给内核；若外壳未传，内核使用与外壳一致的默认值：

| 项 | 默认值 |
|---|---|
| 作息 | 8 节/天，40 分钟/节，08:00 上学，上午 5 节至 12:20，下午 14:30 起至 16:55；第 3 节后大课间 30 分钟，第 6 节后眼操 15 分钟 |
| 固定课 | 周一第 1 节 班会；周一第 8 节 研究性学习；周四第 8 节 校本课 |
| 连堂 | 数学（周二）、语文（周三）、英语（周四），每班每天 1 个 2 节连堂块，块可落在上午 1-2/2-3/3-4/4-5 |

## 最小示例（4 个班）

班级：C01–C04（均为高二理科）

课程（每班）：语文 6（连堂）、数学 6（连堂）、英语 6（连堂）、物理 5、化学 4、生物 3、体育 2
合计 32 节 → 剩余 8 节由内核自动补为自习。

教师：语文 T01/T02、数学 T03/T04、英语 T05/T06、物理 T07/T08、化学 T09/T10、生物 T11/T12、体育 T13/T14
相邻班错开使用同一学科的两位教师，可验证「教师同时段不撞课」约束。
