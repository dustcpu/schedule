# 本次运行确认流程

在读取输入后、调用任何求解器前，生成并展示下表：

| 编号 | 规则 | 默认状态 | 本次状态 | 数值/范围 | 来源 | 是否需要确认 |
|---|---|---|---|---|---|---|

必须逐项询问下列未填写信息：固定时段、周日晚自习班主任规则、多班教师晚自习次数模式、特殊班型的晚自习学科、具名禁排/特殊安排、共享资源分配。

用户可以直接引用编号，也可以用自然语言修改。例如“关闭F20”“周日晚自习不固定班主任”“静校允许第3、4、5、6节有课的教师”。

只有在所有必确认项都有值且用户明确回复“确认”后，才可以求解。无解时输出硬约束冲突和最小放宽候选；不能自动改为软约束。
