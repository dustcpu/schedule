# 四份 Excel 成品格式

1. **总表学科版.xlsx**：一个`总课表`工作表；上方周一、周二、周三，下方周四、周五、周日。每个日块依次显示早读、1—4节、静校、5—8节、晚自习。正式课和三类值班只显示学科。
2. **教师个人课表.xlsx**：一个纵向工作表；先按学科分组，再按教师分块。每块列为周一至周五和周日，行包含早读、1—8节、静校、晚自习；单元格显示班级和学科。
3. **班级课表.xlsx**：一个`各班课表`工作表；班级自小到大纵向分块。每块列为各日，行包含早读、1—8节、静校、晚自习；单元格只显示学科。
4. **早读静校晚自习值班表.xlsx**：一个明细工作表；固定列为日期、班级、值班类型、教师姓名。此工作簿只输出教师姓名，不显示任教学科。

所有四份工作簿必须从同一份已验证正式课 JSON 和值班 JSON 生成。不得手工二次录入或重新求解其中任一份。
