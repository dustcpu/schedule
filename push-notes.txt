这个脚本做了什么
  1. 列出这次改动的文件
  2. 全部暂存，让你写一句说明（直接回车就用默认说明）
  3. 提交
  4. 推送到 GitHub

推送失败怎么办
  · 网络不通，或校园网 / 公司网挡了 443 端口  ->  换个网络，或稍后再试
  · 远程有别人新推的提交                     ->  先在本文件夹执行 git pull，再重跑本脚本
  · 这台机器没有该仓库的推送权限             ->  确认用的是配了 SSH 密钥的那台电脑
  报错原文就在上面几行，截图发给 AI 助手即可。

推送成功之后
  · 到 https://github.com/dustcpu/schedule 可以看到最新提交
  · 如果这次是要「发版」，还需要打 tag 并建 Release —— 那一步让 AI 助手来做
    （本脚本只负责把代码推上去，不会打 tag）
