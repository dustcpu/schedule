# 约束转换器（外置：自然语言 → 结构化排课约束）

把教务老师的自然语言要求（如「张老师不想周二上连堂」）转换成结构化 JSON，
交给排课引擎作为限制条件生效。**全程离线、不联网、不调用任何模型**——
词典命中优先；词典认不出的行，生成一份可外发免费 AI 的提示词（姓名已脱敏），
AI 返回的 JSON 再用本工具校验后才可用（对应《额外约束处理方案评估》方案 1 + 方案 3）。

## 定位

- **外置**：不进 Tauri 发布物、不进引擎进程；是团队/教务的中转工具，也是语料收集器。
- 引擎侧对应能力见 `docs/约束能力清单.md`（写法对照表 / JSON schema / 触发词表）。

## 用法

```bash
# 1) 转换：语料文件（一行一条）+ input.xlsx（姓名对照，只在本地读取）
uv run --with openpyxl python 约束转换器/nl2req.py \
    --text 约束转换器/测试语料/语料_合成.txt \
    --xlsx engine/test_input_25_new/input.xlsx \
    --out structured_requirements.json

#    也可以单句调试：
python 约束转换器/nl2req.py --line "张老师不想周二上连堂" --xlsx <input.xlsx>

# 2) 校验外部 AI 返回的 JSON（逐条校验，坏一条不牵连其他）
uv run --with openpyxl python 约束转换器/nl2req.py \
    --validate ai返回.json --xlsx <input.xlsx> --out structured_requirements.json

# 自测
python 约束转换器/测试语料/自测.py
```

可选 `--hard-limits hard_limits.json`：读取实际的连堂日与上午/下午节次口径
（不给则用引擎默认：上午 1-5 节、下午 6-8 节，数学连堂周二/语文周三/英语周四）。

## 产出（三样）

1. **structured_requirements.json** —— 放进引擎输入目录即可生效（与 input.xlsx 同目录）；
2. **```json 围栏块** —— 整段粘贴进软件「特殊要求」框即可生效（外壳零改动）；
3. 每行的**回显**「我理解成：……」与**预警**（如：数学连堂固定在周二，禁了周二连堂
   等于这位老师不能教数学）——请人工确认后再使用。

## 当前支持的 5 类约束

| 类型 | 自然语言示例 | 生效语义 |
|---|---|---|
| 指定任课 | `T30教C05数学` / `张卫东教高二(1)班物理` | 该班该学科由该教师任教（锁定） |
| 教师不可用 | `张卫东周二没空` / `李梅周四下午不排课` / `T045周五第1-2节请假` | 该教师在这些时段不带课 |
| 教师连堂禁日 | `张卫东不想周二上连堂` | 该教师不担任连堂落在周X的学科的任课 |
| 班级不可用 | `C01班周五第7-8节不排课` / `高二(5)班周一上午安排活动` | 该班这些格只排自习 |
| 教师带班上限 | `张卫东最多带2个班` | 该教师所教班级数 ≤ N |

认不出的行**明确说认不出**（弃权，绝不硬猜），并给出支持写法示例。

## 隐私红线（务必遵守）

- 本工具**只在本地读** input.xlsx，不联网、不上传；
- AI 提示词在输出前会**自动把行内教师姓名/班级名替换成编号**（脱敏后才可外发）；
- 收集到的真实语料如需入库或外发，**必须先脱敏**（姓名 → T001 式占位），
  含姓名的原句不进仓库、不进测试存档。

## 语料收集（覆盖率测量的入口）

`测试语料/语料_合成.txt` 是种子语料（全部占位命名）。收集教务真实说法时：
每行一条 → 本地跑本工具 → 记录「命中/认不出」→ 定期统计词典覆盖率
（覆盖率 >90% 就不必上模型，见《额外约束处理方案评估》§0）。
认不出的句子是扩充词典的原料；确认无真实姓名后可追加进种子语料。
