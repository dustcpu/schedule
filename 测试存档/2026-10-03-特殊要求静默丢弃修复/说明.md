# 2026-10-03 特殊要求「自然语言」被静默丢弃

> 用户实测发现：在「② 特殊要求」里输入两行
> ```
> T030教C05英语
> T48不想周五上课
> ```
> 只有第一行生效，第二行**既没生效、也没任何提示**。

---

## 1. 结论先说

**不是「约束转换器」没生效 —— 是引擎把那一行静默丢掉了。**

软件里的「特殊要求」框**只认两种写法**：

| 写法 | 例子 | 谁来处理 |
|---|---|---|
| ① 教师指定 | `T030教C05英语` | 引擎直接解析 |
| ② JSON 结构化约束 | ` ```json … ``` ` 围栏块 | 引擎直接解析 |

**自然语言的句子（「T48不想周五上课」）引擎看不懂**——设计上要先经过仓库里的
离线转换器（`约束转换器/nl2req.py`）转成 ② 的 JSON。所以它不生效是**预期**的。

**但它不该「什么都不说」**。这是 bug，已修。

---

## 2. 根因

`engine/scheduler/data/load.py` 的 `_parse_teacher_constraints`，判断"这一行算不算要求"时只有两条：

```python
m = re.match(r'^(.+?)\s*[=教]\s*(.+)$', line)     # 含 教 或 =
if not m:
    if re.search(r'[=教]', line):
        unparsed.append(line)              # 「像是教师指定但看不懂」
    elif list_mark_re.match(raw.strip()):
        unsupported.append(raw.strip())    # 「以 1. ① - 开头」→ 要求不支持
    continue                               # ← 其余一律**静默丢弃**
```

`T48不想周五上课` 的处境：

- 不含 `教` → 第 1 条不命中（"上课"的"课"不是"教"）
- 不含 `=` → 同上
- 没写行首编号 → 第 2 条不命中

→ **三条都不命中，直接 `continue`**：没有告警、没有回显，用户只能靠"结果好像少了点什么"去猜。

> 这是最糟的一种失败：**用户以为生效了，实际没有**。比直接报错更糟——
> 报错至少会让人去改。

顺带发现同一函数里的反向问题：`本表由教务处维护` 因为含"教"字，
被切成「本表由教务 / 务维护」后报成"像是教师指定但无法解析" —— 说明文字被当成用户要求，同样困扰人。

---

## 3. 修法

### 3.1 不再静默：补一条「看起来像要求」的启发式

`if not m:` 分支里加第三个判定 —— 行里出现**星期词**或**要求动词 / 连堂词 / 数量限制词**
就当作一条要求，归入"没有生效"并给出改写指引：

```python
day_word_re = re.compile(r'周[一二三四五六日天]|星期[一二三四五六日天]')
req_hint_re = re.compile(
    r'不排|不上|没空|不空|请假|有事|外出|教研|调休|不能|禁止|避免|不要|别排|'
    r'连堂|连排|连着|双节|最多|最少|至少|不超过|上限|下限')
```

**宁可多说一句，也不要静默。** 普通说明文字（「年级：高二」「2026年秋季作息时间」）
不含这些词，不会被误报。

### 3.2 反向收严：说明文字不再被当成「教师指定」

`if not tid:` 分支里，只在左半段**确实像教师**时才报"像是教师指定"：

```python
looks_like_teacher = bool(
    re.search(r'[TCtc]\d{1,4}', t_str)                     # T30 / C05 这类 ID
    or re.fullmatch(r'[\u4e00-\u9fa5]{2,4}老师?', t_str))  # 张三 / 张三老师
```

于是 `本表由教务处维护` 回到"普通说明文字，不打扰"。

### 3.3 告警文案说清「该怎么办」

原来的文案只说"目前仅支持「教师ID教班级ID学科」"，现在两种写法都提，
并指明自然语言可以先过离线转换器：

> 额外约束中有 N 行没有生效：…。目前只认两种写法——①「教师ID教班级ID学科」
> （如 T001教C01语文）；② JSON 结构化约束（把一段 JSON 整段粘进「特殊要求」，
> 格式见界面「书写规范」）。这类自然语言可先用仓库里的离线转换器
> （约束转换器/nl2req.py）转成 JSON 再用。

## 4. 验证

`复现脚本/text_parse_probe.py`（本目录）直接调解析函数，逐条断言归类：

```bash
python text_parse_probe.py
```

| 输入 | 期望 | 说明 |
|---|---|---|
| `T030教C05英语` / `T001=C01语文` | 解析成功 | 受支持的写法 |
| **`T048不想周五上课`** | **报"没有生效"** | ★ 用户实测那一行（修复前静默） |
| `T999教C05英语` / `T001教C99语文` | 报"教师/班级找不到" | 提示具体错在哪 |
| `张老师周二没空` / `C01班周五第7-8节不排课` / `T030最多带2个班` / `数学老师请假` / `张老师不想周二上连堂` | 报"没有生效" | 各类自然语言要求 |
| `年级：高二` / `2026年秋季作息时间` / `3月1日开始执行` / `本表由教务处维护` / `备注：体育课在操场` | **不打扰** | 普通说明文字 |

**16 条全部符合预期。**

> 已知边界：`12班语文每周加一节` 仍不会被报出来（不含明显特征词）。
> 这一类"以数字开头的模糊表述"在 2026-10-01 被特意从误报里排除过，不做过度识别。

cd engine && python build_exe.py            # 产物 engine/dist/engine.exe
