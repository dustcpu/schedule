# 2026-10-09 走班制（选考科目走班）+ 课表输出改版

## 一、输出改版
每个方案的课表从"**每个班一块、纵向堆在同一个 sheet**"改成"**一张横向总表**"：

| | 改前 | 改后 |
|---|---|---|
| 布局 | 每班一块，纵向 25 块 | 一张总表：行 = 天 × 节，列 = 每个行政班 |
| 格子 | 学科 + 教师（两行） | 只写学科（教师仍在「任课表N」） |
| 冻结 | 无 | 冻结「周 / 节」两列 |
| PDF | A4，每页 3 个班 | **A3 横向**，一页一个方案 |

形态与校方在用课表一致（`周 | 节 | 班1 | 班2 | …`）。

## 二、走班功能
输入文件加两张**可选** sheet 即启用；**不加则行为与之前逐字一致**（已回归验证）。

- `走班时间`：独立时间ID / 周次数 / 连排节数 / 参与班级
- `走班教学班`：教学班ID / 独立时间 / 学科 / 来源班级 / 人数 / 教室 / 任课教师
  （一个教学班占多行，第一行给独立时间/学科/教室/教师，后续行只写来源）

引擎行为：
1. 把每个「独立时间」排到合适的时段（连排 `连排节数` 节、每周 `周次数` 次）；
2. 同组的教学班在这些节次**同时开课**；
3. 参与班在这些格**自动让位**（不排常规课）；走班科目的课时由独立时间承载；
4. 教学班的任课教师在这些节次不排常规课。

输出：
- 走班格写多行「学科 → 去向」，并按节次**上色**（连排第一节 `C6EFCE` 绿、第二节 `FFEB9C` 黄）
- 新增「走班表N」sheet：教学班 / 独立时间 / 学科 / 来源（班级 人数）/ 合计 / 教室 / 教师 / 本方案时段

约束编号：**H30** 独立时间落位、**H31** 组内同时开课、**H32** 参与班让位、
**H33** 教学班教师不冲突、**H34** 走班课时计入教学班。

## 三、实测踩到的 5 个坑（都已修，代码里有注释）
1. **`KeyError ('C01','政治',1,1)`** —— 走班课不生成 `x`，但教师候选索引 `cand_of` 仍从
   `p.courses` 收走班课，建 `y/z` 时找不到 `x`。修：`cand_of` 跳过 `is_walk`。
2. **INFEASIBLE（自习补位）** —— 走班格被占住，但 `self_study_fill` 仍按整天 40 格算课时，
   参与班的常规课时超过可用格数。修：扣掉走班课与走班占用格。
3. **INFEASIBLE（校验器误拒）** —— `validate` 的"周课时合计"把走班课也算进去，报 44 > 40
   直接拒绝排课。修：同样扣掉走班课与走班格。
4. **`walk_here` 可能取 2** —— 同一独立时间的两次落位若重叠，`v == sum(terms)` 会让 BoolVar
   取到 2 → 无解。修：加"同一独立时间的多次落位互不重叠"。
5. **`IndexError: DAYS[d]`** —— `DAYS` 是 0-based 的 5 元素列表，新代码误用 1-based。
   修：`DAYS[d - 1]`。

> 另：`verify_hard.load_result_grids` 原本按"每班一块"解析，改成横向总表后会失效，
> 已同步重写；H2 / H25 跳过走班科目（它们的任课与课时都在教学班表里核算）。
