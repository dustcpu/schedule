## 两条阅读提醒

**1. 区分「引擎实测」与「独立压测」。**

- `25班-引擎实测/` = **本项目引擎**跑 `engine/test_input_25/` 的真实结果，分析报告第 3、4 节的数据全部来自这里。
- `压测脚本/` = **另写的独立模型**（不 import 项目代码、数据自建），只用于验证修复方法的可行性。
  它给出的「差异化权重可达 86% 差异度」**不等于**项目引擎改完后的效果。

**2. 二进制文件不入库。**

仓库 `.gitignore` 忽略了 `*.xlsx` 和 `*.pdf`，因此本存档里这两个格式的原始输出**不会进 git**，
只保留 `status.json`、`分析报告.md` 和脚本。需要原始输出时按报告里的命令重新生成即可。
