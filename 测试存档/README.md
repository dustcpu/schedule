## 两条阅读提醒

**1. 区分「引擎实测」与「独立压测」。**

- `25班-引擎实测/` = **本项目引擎**跑 25 班数据的真实结果，分析报告第 3、4 节的数据全部来自这里。
  （2026-09-25 / 2026-09-26 两次跑的是旧格式数据集 `engine/test_input_25/`，已随旧格式移除；
  2026-09-28 那次跑的是新格式 `engine/test_input_25_new/`。）
- `压测脚本/` = **另写的独立模型**（不 import 项目代码、数据自建），只用于验证修复方法的可行性。
  它给出的「差异化权重可达 86% 差异度」**不等于**项目引擎改完后的效果。

  > 后续验证：项目引擎实际改完后实测为 **45.4% ~ 51.1%**（见 `2026-09-28-v0.1.5多解验证/`），
  > 方向一致但数值不同 —— 这正好印证了上面这条提醒的必要性。

**2. 存档只保留课表 xlsx，不保留 PDF。**

仓库 `.gitignore` 忽略了 `*.pdf`，测试存档**不放 PDF**（约定：PDF 体积大、内容与 xlsx 重复）。

- **要保留**：`result.xlsx` —— 完整课表。每个方案 sheet 含全部班级的课表，
  已验证 25 班 × 8 节 × 5 天 = 1000 格全部填满，无空缺。
- **不保留**：`result.pdf` —— 需要时按下方命令重新生成即可。

`.gitignore` 为本目录开了 xlsx 例外：`!测试存档/**/*.xlsx`。

## 复现方式

```bash
cd engine
uv run --with ortools --with openpyxl --with reportlab \
    python engine.py test_input_25_new <输出目录> <任务ID>
```

> 25 班新格式求解约 **2 分 30 秒**，且**并发跑会显著变慢**——
> 实测两份数据同时跑时，其中一份因触及 `GLOBAL_BUDGET` 只给出 4 套方案。
> 复现请一次只跑一份。
